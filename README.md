# KiranaKlick

This is the local version of the KiranaKlick application.

## Run Locally

**Prerequisites:**  Node.js

1.  **Install dependencies:**
    ```bash
    npm install
    ```

2.  **Environment Setup:**
    -   Rename `.env.local.example` to `.env.local` (if applicable) or ensure `.env.local` exists.
    -   Set your `GEMINI_API_KEY` in `.env.local`.

3.  **Run the app:**
    ```bash
    npm run dev
    ```
